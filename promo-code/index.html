프로모션코드 사용방법

프로모션코드는 숙소를 고른 뒤 결제 화면에서 넣습니다. 접속부터 결제까지 한 창에서 이어가면 적용 오류가 줄어듭니다.

  1. 01

    버튼으로 아고다 접속

    전용 링크를 거쳐야 적용되는 프로모션코드가 있으니 아래 버튼으로 들어가세요.

  2. 02

    로그인

    회원 전용 할인과 신규회원 조건이 로그인 상태에서 판단됩니다.

  3. 03

    지금 결제 객실 고르기

    나중 결제·현장 결제 요금은 입력란이 보이지 않거나 할인에서 빠질 수 있습니다.

  4. 04

    예약자 정보 입력

    투숙객 이름과 연락처를 넣고 결제 단계로 넘어가세요.

  5. 05

    프로모션코드 입력

    결제 화면의 할인코드 입력란을 열고 문자열을 대소문자 그대로 넣은 뒤 적용을 누르세요.

  6. 06

    할인 금액 확인 후 결제

    요금 요약에 할인 줄이 생겼는지, 세금·봉사료 포함 총액이 줄었는지 확인하세요.

Q

아고다 프로모션코드와 할인코드는 다른가요?
A

같습니다. 결제 화면의 같은 입력란에 넣으며 규칙도 같습니다.

Q

프로모션코드 두 개를 같이 넣을 수 있나요?
A

넣을 수 없습니다. 예약 금액에 맞는 하나를 골라 넣으세요.

Q

앱에서도 프로모션코드를 쓸 수 있나요?
A

앱에도 입력란이 있지만, 전용 링크 경유가 필요한 할인코드는 웹에서 적용이 더 확실합니다.

Q

국내 숙소에도 12% 프로모션코드가 되나요?
A

해외 숙소 전용이라 국내 숙소에는 적용되지 않습니다.

Q

카드 할인과 프로모션코드를 함께 받을 수 있나요?
A

대부분 받을 수 있습니다. 다만 카드 브랜드 전용 할인코드는 입력란을 차지하니 금액을 비교해 고르세요.

Q

예약을 취소하면 프로모션코드를 다시 쓸 수 있나요?
A

할인코드마다 다릅니다. 1회용이면 복구되지 않을 수 있으니 무료 취소 기한을 먼저 확인하세요.

할인율과 한도는 바뀔 수 있으니 결제 화면에서 최종 금액을 확인하세요.
